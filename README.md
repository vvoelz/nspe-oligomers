# NSPE-Oligomers

A repository for the structural and analytical data of NSPE oligomers, including NMR assignments, peptoid trajectory analysis, and utilities for preparing distance-restrained HREX simulations.

## 📑 NMR Assignments

Directory: [`nmr_assignment/`](./nmr_assignment/)

- Contains Excel sheets detailing:
  - NMR restraint calculations
  - Intensity assignments

---

## 🧪 Peptoid Trajectory Analysis

Directory: [`peptoid/`](./peptoid/)

Includes trajectory analysis code for the following structures:

- `nspe-7-1`
- `nspe-7-2`
- `nspe-10`

---

## 🛠️ Utilities

Directory: [`untils/`](./untils/)

- Scripts for:
  - Parsing input data
  - Creating distance-restrained HREX files
